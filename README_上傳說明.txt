成語功夫學院 網站資料夾說明
================================
這個資料夾放到網路空間後,學生用瀏覽器開一次網址並「加入主畫面」,之後不需要網路、不需要任何帳號。

【用 GitHub Pages 免費上傳(一次設定)】
1. 到 github.com 註冊並登入(免費)。
2. 右上角「+」→ New repository,名稱輸入 idiom(英文小寫),選 Public,按 Create repository。
3. 在新頁面點「uploading an existing file」,把本資料夾裡的所有檔案拖進去
   (index.html、sw.js、manifest.webmanifest、三個 icon-*.png、.nojekyll),按 Commit changes。
   注意:index.html 約 15 MB,網頁上傳上限是 25 MB,可以上傳。
4. 進入 Settings → Pages,Source 選 Deploy from a branch,Branch 選 main、資料夾選 /(root),按 Save。
5. 等 1~2 分鐘,網址會是:https://你的帳號.github.io/idiom/
   (GitHub Pages 的網址是公開的,任何人知道網址都能打開;學習紀錄只存在學生自己的裝置上。)

【學生端(iPad / iPhone)】
1. 連上網路,用 Safari 開上面的網址,等畫面完整出現(第一次要下載約 15 MB)。
2. 點下方「分享」按鈕 → 加入主畫面 → 新增。
3. 之後從主畫面的「成語功夫學院」圖示開啟,就算沒有網路也能玩。

【學生端(Android / 電腦 Chrome)】
開啟網址,等畫面出現後,從瀏覽器選單選「安裝應用程式」或「加到主畫面」。

【更新版本】
重新上傳新的 index.html 與 sw.js 取代舊檔。學生下次連上網路開啟時會自動更新。

【學校 Wi-Fi 限制(v53 起)】
- 成語功夫學院會向「國小跨校智慧教學網站」確認這台裝置是否連在管理員指定的學校網路。
- 管理員在該網站後台「學校網路」加入學校的對外網路，並開啟學生限制後，才會真的限制；未開啟時一律可用。
- 離開學校網路超過 12 小時，畫面會自動鎖住，回到學校 Wi-Fi 按「重新檢查」即可解鎖。
- 沒有指定網路時，第一次使用就需要連上學校 Wi-Fi。
